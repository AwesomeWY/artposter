# assets

## 기관 CI(로고) 넣는 법

`pomodoro.html` 헤더는 아래 경로의 이미지를 자동으로 불러옵니다.

```
assets/nia-ci.png
```

- 기관에서 배포한 **공식 CI 원본 파일**을 위 이름으로 저장하세요.
- 권장 규격: 배경 투명 PNG 또는 SVG, 짧은 변 200px 이상 (헤더에서 52×52로 축소 표시).
- SVG를 쓰려면 `pomodoro.html`의 `<img id="org-logo" src="assets/nia-ci.png">` 에서
  확장자만 `assets/nia-ci.svg` 로 바꾸면 됩니다.
- 파일이 없으면 헤더는 자동으로 `NIA` 텍스트 마크로 대체 표시되므로,
  로고 없이도 페이지는 정상 동작합니다.

> 공공기관 CI는 기관의 표기 지침(색상·여백·최소 크기·변형 금지)을 따라야 합니다.
> 배포 전 담당 부서의 표기 규정을 확인하세요.
