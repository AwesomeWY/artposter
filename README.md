# artposter

브라우저에서 바로 열리는 단일 파일(single-file) 정적 웹앱 모음입니다. 빌드 도구·서버·API 키가 필요 없습니다.

| 파일 | 앱 | 설명 |
|---|---|---|
| `index.html` | Wanderlust Bauhaus Poster Maker | 바우하우스 스타일 여행 포스터 생성기 |
| `game.html` | **GAME FORGE** | 키워드로 게임을 만들고 그 자리에서 플레이하는 웹앱 |

## GAME FORGE (`game.html`)

장르를 고르고 좋아하는 키워드를 입력하면 테마·색·캐릭터·속도·규칙이 조합된 게임이 생성되고,
같은 화면에서 즉시 플레이할 수 있습니다.

### 1. 제작 방식

```
장르 선택  →  키워드 입력  →  난이도 선택  →  [게임 만들기]  →  [지금 플레이]
```

- **장르 6종**: 테트리스 / 두더지 잡기 / 액션 서바이벌 / 레이싱 / 벽돌깨기 / 스네이크 — 전부 실제 플레이 가능
- **키워드 → 테마**: 16종 테마 사전(우주, 심해, 숲, 네온 시티, 괴담, 동물, 음식, 설원, 사막, 레트로, 판타지, 공장, 학교, 화산, 꽃밭, 스타디움)에 매칭.
  사전에 없는 키워드는 문자열 해시로 **고유 팔레트를 합성**하므로 어떤 입력이든 결과가 나옵니다.
- **보정어(modifier)**: `빠른 / 느린 / 폭풍 / 한적 / 거대 / 미니 / 쉬운 / 어려운 / 밤` 등이
  속도·밀도·크기·관대함·명도에 실제 수치로 반영됩니다.
- **결정론적 생성**: `장르 + 키워드 + 난이도 + nonce`를 FNV-1a 해시 → mulberry32 PRNG 시드로 사용.
  같은 입력이면 항상 같은 게임이 나오고, `🎲 다시 생성`은 nonce만 올려 변주합니다.

생성 결과는 `GameSpec` 한 덩어리(팔레트·스프라이트·스탯 4종·장르별 수치 파라미터·규칙 문장)로 만들어져
게임 엔진에 주입됩니다.

### 2. 플레이

- 키보드: `← →` 이동, `↑ / X` 회전, `↓` 소프트드롭, `Space` 하드드롭·발사, `C` 홀드, `P` 일시정지, `R` 재시작, `Esc` 나가기
- 모바일: 게임별 가상 D패드 + 캔버스 탭·드래그(두더지는 탭 타격, 액션은 드래그 이동, 벽돌깨기는 드래그 패들)
- 최고 점수는 장르별로 `localStorage`에 저장됩니다.

### 3. 보관함 · 공유

- `＋ 보관함`: 만든 게임을 브라우저에 최대 30개까지 저장하고 목록에서 바로 플레이
- `🔗 링크 복사`: `#g=snake&d=hard&n=2&k=심해%20폭풍` 형태의 URL 해시로 공유.
  링크를 열면 동일한 게임이 그대로 복원됩니다.

### 4. 실행

```bash
# 그냥 파일을 열거나
open game.html

# 로컬 서버로
npx http-server . -p 8080   # → http://localhost:8080/game.html
```

의존성은 Google Fonts(Space Grotesk, Noto Sans KR)뿐이며, 오프라인에서도 시스템 폰트로 정상 동작합니다.
